When discussing travel itineraries, always refer to places as "Korean/foreign name (English description)" — e.g., "Gyeongbokgung (main royal palace)", "Bar Cham (Korean spirits hanok bar)", "Jamsil Stadium (KBO baseball)". This lets the user track locations without needing to memorize foreign names.

**Why:** User explicitly requested this mid-session to stay oriented during dense itinerary planning.

**How to apply:** Every time a place name is mentioned in travel planning, include a brief English descriptor in parentheses. Even on second/third mention within the same conversation.
